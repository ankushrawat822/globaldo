# GlobalDo
A public global to-do board where people post tasks and others offer to help. Contacts are revealed only on mutual consent.

## Setup
1. `npm install`
2. Create a Supabase project (or `npx supabase start` locally). Copy `.env.example` → `.env.local` and fill in values.
3. `npx supabase db reset`
4. `npm run dev`

See `CLAUDE.md` and `docs/` for everything else.
